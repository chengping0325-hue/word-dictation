## 一、产品定位

「口袋工具」是一个工具集小程序，首页以宫格形式展示各工具入口，方便后续持续扩展新工具。

**当前工具：**
- 单词听写（新开发，核心功能）
- 城市书斋（占位卡片，后续集成）

**商业模式：** 免费 + 广告（暂不做付费，后期接入广告）

```

─────────────────────────────

│   🎧     │  │   📚     │
```

- 右上角头像点击进入个人中心

---

### 2.2 单词听写 — 主页面

唯一主界面，无底部 Tab 导航。

- 顶部：标题「单词听写」+ 返回按钮
- 单词录入区：手动输入 + 拍照上传（两个并列入口）
- 单词列表：可拖拽排序，单条删除 + 一键清空（无单词时显示空状态）
- 设置区：朗读次数（1-5次）、间隔时间（1-10秒）
- 底部：「开始听写」主按钮（无单词时置灰）

---

### 2.3 单词听写 — 听写进行中

全屏专注模式。

- 顶部：返回 + 进度（3 / 10）
- 中间：SVG 扬声器图标 + 播放次数进度点
- 下方：倒计时卡片
- 播放完所有单词后自动跳转判分页
- 支持暂停 / 继续

---

### 2.4 单词听写 — 判分页

- 拍照 / 相册上传答卷（大点击区域）
- OCR 识别进度条
- 逐行对比结果（✅正确绿色 / ❌错误红色 + 正确答案）
- 得分展示（X / Y，百分比）

---

### 2.5 个人中心

从首页右上角头像进入。

- 微信头像 + 昵称
- 单词本：按日期分组，显示历次听写记录，错误单词标红

## 三、核心功能

### 3.1 微信登录
- `wx.login` 获取 code，换取 openid
- CloudBase Auth 管理用户身份
- 首次打开自动静默登录，无需用户手动操作

### 3.2 单词录入
- 手动输入：输入框逐条添加
- 拍照 OCR：调用 `wx.chooseMedia` 拍照，Tesseract.js 识别英文单词
- OCR 封装为独立模块，预留后期切换 AI 模型接口

### 3.3 TTS 发音
- 使用微信小程序 `InnerAudioContext` + 有道/百度 TTS API
- 按设置播放 N 次，每次间隔 X 秒，自动进入下一个

### 3.4 OCR 判分
- `wx.chooseMedia` 拍照上传答卷
- Tesseract.js 识别手写英文
- 与原始单词列表逐一比对（大小写不敏感完全匹配）

### 3.5 数据存储
- 用户信息、听写记录存储在 CloudBase 文档型数据库
- 单词本按日期分组，永久保留历史记录
