# 单词听写 · 功能升级与 UI 重做设计文档

**日期**：2026-05-16
**状态**：待审阅
**适用范围**：仅"单词听写"模块（口袋工具首页结构不变）

---

## 1. 背景与目标

「单词听写」是「口袋工具」小程序当前唯一可用的工具。本次升级要解决三个问题：

1. **OCR 不可用** — 现有腾讯云 OCR 云函数密钥是占位符，从未真正跑通
2. **UI 风格朴素** — 现有页面是基础卡片样式，缺少视觉打磨
3. **功能受限** — 只支持英文单词、不支持拖动排序、不能在听写过程中显隐单词

目标：换 OCR 实现 + UI 整体重做 + 加 3 个能力（中英混合 / 拖动排序 / 听写时显隐）。

## 5. 页面设计

### 5.1 口袋工具首页（`pages/index/`）

**改动**：结构不变，仅做视觉适配（系统灰底 + 白色卡片 + 系统蓝点击态）。
**移除**：右上角头像（profile 入口）。

### 5.2 听写 tab（`pages/dictation/`）

**结构**（从上到下）：

1. 导航栏：`‹ 口袋工具` 单词听写
2. Section "添加单词"
   - 输入框 + 「添加」按钮（一行）
   - 「📷 拍照识别」按钮（一行，点击调微信 OCR 录入单词）
3. Section "单词列表 · N 个"
   - 列表行，每行一个单词，右侧"删除"红字
   - **长按行可拖动排序**（用 `movable-area` + `movable-view` 或第三方组件实现）
   - 列表为空时显示空状态卡片
4. Section "朗读设置"
   - 朗读次数：stepper（1–5 次）
   - 间隔时间：stepper（1–10 秒）
   - ~~显示单词~~ ← **不在这里**
5. 底部固定 FAB：「开始听写」（蓝色主按钮，单词列表为空时禁用）
6. 底部 tab 组件（听写 / 单词本）

**输入规则**：
- 输入支持中英混合，去除前后空格
- 单一输入框，不做语言切换
- 不限制字符（中文词、英文单词、字母数字混合都可）

**拖动排序交互**：
- 长按 ≥ 300ms 触发拖动态（视觉提示：背景变 `#F2F2F7`，轻微放大 1.02）
- 拖动时其他行让位（动画 200ms）
- 松手后 `setData` 更新 words 数组顺序

### 5.3 听写中（`pages/playing/`）

**结构**：

1. 导航栏：`‹ 退出` 2/5 `👁`（眼睛图标 = 显示/隐藏切换）
2. 居中区域：
   - 上方："单词 X / N" 副文字
   - 中央喇叭圆按钮（直径 220rpx，系统蓝，阴影）
   - 单词显示区：
     - **隐藏态（默认）**：`●●●●`（灰色 ●，根据单词长度显示对应数量）
     - **显示态**：当前单词大字号（60rpx 加粗）
   - "正在播放第 X / N 次" 状态文字
   - 圆点进度（done / active / pending）
3. 底部："暂停"按钮（白底红字）

**「眼睛」切换**：
- 默认隐藏（标准听写场景）
- 点击右上角眼睛图标 toggle：隐藏 → 显示 → 隐藏
- 切换状态**仅在本次听写中有效**，不持久化（下次进入回到默认隐藏）

**喇叭圆按钮**：
- 播放中：脉冲动画
- 暂停：静止 + 透明度降低

### 5.4 批改页（`pages/grading/`）

**三个状态**：

#### 状态 1：上传答卷（首屏）

1. 导航栏：`‹ 听写` 批改
2. Section "上传手写答卷"
   - 大虚线框拍照入口（`📷 拍照 / 从相册选择` + 副文字"拍下你的纸张"）
   - 点击调 `wx.chooseMedia` → 拿到照片
3. Section "本次听写"
   - 文字"共 N 个单词，正在等你的答卷…"
   - 单词预览（chips 形式，仅展示）

#### 状态 2：OCR 识别中

- 居中 loading：圆形 spinner + "正在识别" + "微信 OCR 处理中"
- 通常 1–3 秒

#### 状态 3：对比结果

1. 蓝紫渐变得分卡（`#007AFF → #5856D6`）
   - "本次得分" 小字
   - "4 / 5" 大数字
   - "正确率 80%" 小字
2. Section "对比结果"
   - 逐词列表
   - 正确：黑字 + 绿色 ✓
   - 错误：红字 + 副文字"你写了「xxx」" + 红色 ✗
3. 底部 FAB：「完成，查看单词本」（点击保存到云数据库 → 跳到单词本 tab）

### 5.5 单词本 tab（`pages/wordbook/`，新增）

替代旧 `pages/profile/`。

**结构**：

1. 导航栏：`‹ 口袋工具` 单词本
2. 卡片列表，按时间倒序，每张卡片：
   - 日期时间（"今天 19:42" / "昨天 16:20" / "5/14 09:15"）
   - 正确率（4/5 正确，颜色根据正确率：高=绿、中=橙、低=红）
   - 单词 chip 列表（正确背景灰，错误背景浅红 + 红字）
3. 空状态：居中 "📖 还没有听写记录"
4. 底部 tab 组件

**数据**：从云数据库 `sessions` 集合按 openid 查询，按 `createdAt desc` 排序。

## 6. 关键功能改动

### 6.1 OCR：腾讯云 → 微信 OCR 插件

**用在两处**：
1. 听写 tab → 拍照录入单词
2. 批改页 → 识别手写答卷

**实现**：
- 使用微信官方 OCR 插件（具体 appid 在小程序后台「设置 → 第三方设置 → 插件管理」添加，实施时确认）
- 同时支持中英文识别
- 在 `app.json` 的 `plugins` 字段声明后即可调用
- **删除 `cloudfunctions/ocrWords/`**（不再需要云函数转发）
- 改在小程序前端直接调用插件 API（不需要 secret key，不消耗云函数额度）
- 备选方案：若官方 OCR 插件不可用，使用 `wx.canvasToTempFilePath` + 微信原生 `wx.ocr` API（基础库 ≥ 2.20.1）

**OCR 输出处理**：
- 录入单词场景：按空格 / 换行切分识别到的文本，去重，加入单词列表
- 识别答卷场景：同样按空白切分，按顺序作为"学生写的内容"传给对比逻辑

**降级**：插件调用失败时，提示"识别失败，请重试或手动输入"。

### 6.2 对比逻辑改造（`utils/compare.js`）

```
当前：强制 lowercase 后字符串相等比较 → 中文失效
改为：trim 后字符串相等比较，仅当两边都是纯英文时才统一 lowercase
```

伪代码：
```javascript
function normalize(s) {
  const trimmed = (s || '').trim()
  return /^[a-zA-Z]+$/.test(trimmed) ? trimmed.toLowerCase() : trimmed
}
function compareWords(original, written) {
  return original.map((word, i) => ({
    original: word,
    written: written[i] || '（未识别）',
    correct: normalize(word) === normalize(written[i] || '')
  }))
}
```

### 6.3 TTS 中英判断（`utils/tts.js`）

当前使用有道 dictvoice：`https://dict.youdao.com/dictvoice?audio=word&type=2`

- `type=2` 是英音口音参数，对**英文单词**正常发音
- 对**中文词**的支持需在实施时实测确认（有道接口对中文一般也能发音，但语速/语调可能不理想）

**实施时按以下顺序验证**：

1. 先实测有道接口对中文是否可接受 — 若可接受，根据 `/[一-龥]/` 检测，含中文时不传或换参数
2. 若有道效果差，改用其他方案：
   - 微信原生 `wx.createInnerAudioContext` + 后端 TTS 服务（如阿里云 / Azure / 火山）
   - 云函数封装 TTS 调用，返回音频文件 URL

**降级**：单词朗读失败时跳过该词、不阻塞流程，并在听写中页底部提示"该词朗读失败"。

### 6.4 自定义底部 tab 组件（`components/inner-tabbar/`）

- 通过 properties 接收当前 active tab（'listen' 或 'wordbook'）
- 点击触发 `wx.redirectTo` 切换页面
- 用毛玻璃背景：`background: rgba(249,249,249,0.94); backdrop-filter: blur(20rpx);`

### 6.5 单词列表拖动排序

- 用 `movable-area` + `movable-view` 实现
- 长按 300ms 进入拖动态
- 拖动结束更新 `data.words` 顺序
