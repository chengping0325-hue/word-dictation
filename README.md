# 单词听写喵

一个帮助小学生完成英语和中文听写练习的微信小程序。家长可以手动录入或拍照导入听写内容，孩子根据语音完成听写，再通过拍照识别进行自动判分和错词整理。

## 主要功能

- 支持英文单词、英文句子、中文词语和中文句子
- 自动识别内容类型并选择对应语音
- 支持手动录入与拍照 OCR 导入
- 自动朗读、重听、暂停和跳转下一题
- 拍照识别答卷并自动判分
- OCR 识别失败时可手动核对
- 自动整理历史记录和错词
- 内置问题反馈入口，长按二维码直接添加客服微信
- 使用微信云开发保存用户与听写数据

## 项目结构

```text
.
├── miniprogram/       # 微信小程序前端
├── cloudfunctions/    # 登录、OCR、会话和 TTS 云函数
├── docs/              # 产品、页面、数据模型与服务文档
└── project.config.json
```

> 📌 **反馈二维码**：`miniprogram/assets/feedback-qrcode.png` 是企业微信「联系我」
> **渠道活码**（512×512，36KB）。后台可随时更换接待成员，**图片不用变、不用重新发版**。
> 若要换码，保留四周 16px 白边（静区），裁切后务必验证能解码。

## 本地运行

1. 使用微信开发者工具导入仓库根目录。
2. 在 `project.config.json` 中确认小程序 AppID。
3. 创建或选择微信云开发环境。
4. 上传并部署 `cloudfunctions/` 中需要使用的云函数。
5. 如使用腾讯云 TTS，在云函数环境变量中配置 `SecretId` 和 `SecretKey`，不要将密钥写入代码。

## 隐私与安全

- 本机私有配置 `project.private.config.json` 不提交到仓库。
- 腾讯云访问密钥仅通过云函数环境变量读取。
- 隐私政策及上线检查清单位于 `docs/`。
